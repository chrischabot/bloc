# `bloc.v3`

REST mapping: [`/api/v3`](../api/endpoints/internal-v3.md). Behavioural-equivalent to `www.notion.so/api/v3`; intended for use with `<NotionRenderer/>` from `react-notion-x`.

## Types

```ts
type V3Table =
  | 'block' | 'space' | 'collection' | 'collection_view'
  | 'notion_user' | 'discussion' | 'comment';

type V3Command = 'set' | 'update' | 'listAfter' | 'listBefore' | 'listRemove';

interface V3RecordMap {
  block?:           Record<string, { role: string; value: Record<string, unknown> }>;
  space?:           Record<string, { role: string; value: Record<string, unknown> }>;
  collection?:      Record<string, { role: string; value: Record<string, unknown> }>;
  collection_view?: Record<string, { role: string; value: Record<string, unknown> }>;
  notion_user?:     Record<string, { role: string; value: Record<string, unknown> }>;
  discussion?:      Record<string, { role: string; value: Record<string, unknown> }>;
  comment?:         Record<string, { role: string; value: Record<string, unknown> }>;
}

interface V3Operation {
  id:      string;
  table:   V3Table;
  path:    string[];
  command: V3Command;
  args:    unknown;
}

interface V3Transaction {
  id?:        string;
  spaceId:    string;
  operations: V3Operation[];
}
```

## `bloc.v3.loadPageChunk(args) → Promise<V3LoadPageChunkResponse>`

```ts
args: { pageId: string; limit?: number; chunkNumber?: number }
```

Returns `{ recordMap, cursor: { stack } }`. Call again with the same `pageId` and the returned stack until the stack is empty.

## `bloc.v3.getRecordValues(args) → Promise<V3GetRecordValuesResponse>`

```ts
args: { requests: Array<{ table: V3Table; id: string }> }
```

Returns `{ results: Array<{ role, value } | null> }` — `null` when the record is missing or hidden.

## `bloc.v3.syncRecordValues(args) → Promise<V3SyncRecordValuesResponse>`

```ts
args: { requests: Array<{ pointer: { table: V3Table; id: string }; version: number }> }
```

Returns a `recordMap` containing only records whose version has advanced beyond the supplied `version`.

## `bloc.v3.submitTransaction(args) → Promise<V3SubmitTransactionResponse>`

```ts
args: { requestId?: string; transactions: V3Transaction[] }
```

Returns `{ object: 'transaction_result', applied, skipped }`.

## `bloc.v3.loadUserContent() → Promise<V3LoadUserContentResponse>`

No arguments. Returns the bootstrap `recordMap` for the current user (workspaces, recent pages, current spaceId).

## `bloc.v3.queryCollection(args) → Promise<V3QueryCollectionResponse>`

```ts
args: {
  collection:     { id: string };
  collectionView?: { id: string };
  loader?: {
    type?:        string;
    limit?:       number;
    searchQuery?: string;
    filter?:      Record<string, unknown>;
    sort?:        Array<Record<string, unknown>>;
  };
}
```

## `bloc.v3.queryCollectionV2(args) → Promise<V3QueryCollectionResponse>`

Same shape as `queryCollection`. The Bloc serialiser emits the same response from both — pick whichever your renderer expects.

## Compatibility

The v3 shape evolves with `react-notion-x`. If you upgrade `react-notion-x` and see render bugs, run the v3 contract tests from `tests/contract/internal-v3/` against your Bloc server.
