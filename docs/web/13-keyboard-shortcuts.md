# Keyboard shortcuts

Bloc's full shortcut set. Where shortcuts differ between platforms, ⌘ is mac, Ctrl is everywhere else.

## Navigation

| Shortcut | Action |
|---|---|
| ⌘P / Ctrl+P | Quick-find page |
| ⌘K / Ctrl+K | Global search |
| ⌘[ / Ctrl+[ | Back |
| ⌘] / Ctrl+] | Forward |
| ⌘⇧M / Ctrl+Shift+M | Open inbox |
| ⌘N / Ctrl+N | New page |
| ⌘⇧N / Ctrl+Shift+N | New window |
| ⌘\\ / Ctrl+\\ | Toggle sidebar |

## Editor

| Shortcut | Action |
|---|---|
| / | Slash menu |
| @ | Mention |
| ⌘B / Ctrl+B | Bold |
| ⌘I / Ctrl+I | Italic |
| ⌘U / Ctrl+U | Underline |
| ⌘⇧X / Ctrl+Shift+X | Strikethrough |
| ⌘E / Ctrl+E | Inline code |
| ⌘K / Ctrl+K | Add link to selection |
| ⌘⇧H / Ctrl+Shift+H | Highlight color cycle |
| Tab / Shift+Tab | Indent / outdent list item |
| Enter | New block |
| Shift+Enter | Soft line break inside the same block |
| ⌘A / Ctrl+A | Select block; press again for whole page |
| ⌘D / Ctrl+D | Duplicate block |
| ⌘⇧↑ / Ctrl+Shift+↑ | Move block up |
| ⌘⇧↓ / Ctrl+Shift+↓ | Move block down |
| ⌘/ / Ctrl+/ | Toggle to-do checkbox / cycle status |

## Modes

| Shortcut | Action |
|---|---|
| ⌘⇧L / Ctrl+Shift+L | Toggle reading (non-editable) mode |
| ⌘⇧S / Ctrl+Shift+S | Open share panel |
| ⌘⇧A / Ctrl+Shift+A | Open AI panel |
| ⌘⇧K / Ctrl+Shift+K | Open keyboard shortcut reference |

## Database

| Shortcut | Action |
|---|---|
| ⌘⇧↵ / Ctrl+Shift+↵ | Open row as full page |
| ⌘↵ / Ctrl+↵ | Open row in side peek |
| ⌘F / Ctrl+F | Inline find within current view |
| ⌘⇧F / Ctrl+Shift+F | Filter |
| ⌘⇧O / Ctrl+Shift+O | Sort |
| N | New row (in board view, in the focused group) |

## System

| Shortcut | Action |
|---|---|
| ⌘Z / Ctrl+Z | Undo |
| ⌘⇧Z / Ctrl+Shift+Z | Redo |
| ⌘P / Ctrl+P (top bar) | Print |
| Esc | Close overlay / blur input |
