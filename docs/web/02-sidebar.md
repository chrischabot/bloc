# Sidebar & navigation

## Sections

The sidebar is organised top to bottom:

1. **Workspace switcher** — click the workspace name to switch between workspaces you belong to. Bottom of the menu has "Create or join workspace".
2. **Quick actions** — Search, Home, Inbox, Settings & members. Each has a fixed keyboard shortcut.
3. **Favorites** — pinned pages.
4. **Private** — pages you've created at the workspace root that no one else can see.
5. **Workspace** — pages anyone in the workspace can see.
6. **Teamspaces** — group-scoped page trees.
7. **Shared** — pages others have shared specifically with you.
8. **Trash** — soft-deleted items (30 days).

## Page tree

- **Expand** — click the arrow on the left of a page. Lazy-loaded: children only fetched when expanded.
- **Drag** — grab the page row; drop on another page to nest, drop between rows to reorder.
- **Right-click** — opens the page menu (rename, duplicate, delete, move, copy link, share, …).
- **Add child** — hover a page, click the `+`.

## Search

⌘K / Ctrl+K. Type to query; results are grouped by type (Pages, Databases, Comments, People). Each result has:

- Title, breadcrumb, last-edited timestamp.
- Snippet with the matched substring highlighted.
- Icon — same as the page icon.

Filters live above the input: `Type:` Pages/Databases/Both; `In:` workspace/teamspace/page; `Sort:` relevance/recent.

## Home

A dashboard surfacing:

- Recently viewed
- Mentioned you
- Upcoming reminders
- Workspace highlights (configured per workspace)
