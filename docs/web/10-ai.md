# AI surfaces

Bloc ships five AI surfaces, all backed by the same `/v1/ai/*` endpoints.

## Writer

Inline completion inside the editor. Triggers:

- Press space at the start of an empty line → an "AI: Press tab to write" hint.
- Slash menu → "Write with AI".
- Select text → floating toolbar → "Ask AI" → choose a transform (continue / rewrite / summarise / translate / fix grammar).

The response replaces or appends to the selection in place. Undo restores the previous state.

## Q&A

Top bar **AI** → **Ask**. A search-style input. Ask anything; the answer is grounded in pages you can read, with inline citations linking back to source pages.

Answers cache per `(workspace, query, index_version)` for 1 h. The "refresh" button bypasses the cache.

## Agent

Top bar **AI** → **Agent**. Give it a goal in natural language; the agent uses tools (search, read page, create page, update property, run a chart, send a webhook) until it answers.

Each step is shown in a collapsible list with input/output. Failed steps are flagged but the run continues unless `on_error: "stop"` is configured.

Limits:

- `max_iterations` — default 10, configurable per run (`Settings → Agent`).
- The agent only touches pages the caller can read; writes obey the caller's ACL.

## Autofill

In a database, hover an empty cell → ✨ icon. Click to fill from context:

- For `select` / `status` — proposes a value with reasoning.
- For `rich_text` / `title` — generates content.
- For `formula` — never autofilled (calculation is deterministic).

Configure default instructions per column in the property settings.

## Meeting Notes

A pre-built template + automation:

1. Start a meeting → page → Slash → "Meeting Notes".
2. Bloc creates a page from the template (attendees, agenda, transcript, summary).
3. After the meeting, paste the transcript; click **Summarise** → Bloc runs Q&A over the transcript.
4. Action items detected as to-do blocks become rows in your Tasks database (if connected).

## Configuration

Bloc proxies to the LLM provider you've configured (`AI_PROVIDER` env). With `AI_PROVIDER=stub`, responses are deterministic placeholders — use this for CI.

| Provider | env |
|---|---|
| OpenAI | `AI_PROVIDER=openai`, `OPENAI_API_KEY` |
| Anthropic | `AI_PROVIDER=anthropic`, `ANTHROPIC_API_KEY` |
| Local | `AI_PROVIDER=local`, `LOCAL_AI_BASE_URL` (OpenAI-compatible) |

Model selection is per-call via the SDK's `model: 'default' | 'fast' | 'advanced'`. The mapping from these to provider model names is in `packages/ai/src/models.ts`.

## What Bloc does *not* claim about AI quality

Answer quality depends on your LLM. Bloc reproduces the *surfaces* and the *citation model*; we don't reproduce Notion AI's retrieval or prompt engineering, which are not public.
