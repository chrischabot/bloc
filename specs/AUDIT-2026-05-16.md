## Code smells found and addressed

### Deleted vestigial scaffolding (16 files)

Phase 0 created package scaffolds for every conceivable subsystem. Real work landed in different packages, leaving empty scaffolds. Universal DoD forbids orphaned files, so these were removed:

- `tests/contract/placeholder.test.ts` — Phase 0 stub; real contract tests now in `tests/contract/sites.test.ts` and `tests/sdk-progressive/*.test.ts`
- `tests/integration/` (entire package) — never populated; real integration tests live in `apps/api/src/routes/*.test.ts` and `tests/contract/`
- `tests/unit/` — README only; unit tests live alongside source in `*.test.ts` files
- `tests/benchmark/` — README only; benchmarks live in `tools/benchmark/scenarios/`
- `tools/seed/` — README only; real seed in `packages/db/scripts/seed.ts`
- `tools/codegen/` — README only; types live in `packages/shared/`
- `tools/screenshot/` — README only; visual regression deferred to Phase 13/20/23
- `packages/editor/` — exported only `EDITOR_VERSION`; live editor components live in `apps/web/components/{BlockRenderer,SlashMenu,FormattingToolbar,DragHandle}.tsx`. The `@bloc/editor` workspace dep was removed from `apps/web/package.json` and `next.config.mjs`'s `transpilePackages`.

### Tightened type lies (down from 20 → 11 `as unknown as`)

`apps/web/components/WebVitalsBeacon.tsx` previously used `as unknown as PerformanceEntryLike` (a local interface) on all five observed metrics. Replaced with proper DOM subtypes:

- LCP → `LargestContentfulPaintEntry` (local extension of `PerformanceEntry`)
- FCP → `PerformancePaintTiming`
- INP → `PerformanceEventTiming`
- CLS → `LayoutShiftEntry` (local extension)
- TTFB → `PerformanceNavigationTiming`

`packages/db/src/repositories/webhooks.ts` + `apps/api/src/routes/webhooks.ts` previously had `as unknown as string[]` casts when reading `subscribedEvents`. Replaced by typing the JSONB column directly with Drizzle's `.$type<string[]>()` on the schema; downstream code dropped the casts.

Remaining `as unknown as` (all defensible):

| File | Count | Reason |
|------|-------|--------|
| `apps/web/components/BlockRenderer.tsx` | 6 | Defensive payload casts for arbitrary block JSON content (file/image/video/audio variants); could be tightened by narrowing `BlockObject` payload types per kind |
| `packages/shared/src/automations/index.ts` | 3 | Generic `renderTemplateDeep<T>` return-type erasure; standard pattern for deep transformers |
| Test files | 2 | Tests cast SDK responses to concrete shapes for assertions |

### Zero placeholder markers

`grep -E "TODO|FIXME|XXX|HACK"` against 293 production sources returns **zero matches**. Likewise no `@ts-ignore` / `@ts-expect-error`. No `console.log` in production paths (single occurrence is inside a sample code-block string in the `/editor` playground demo).

### No dead commented-out code

`grep ^\s*//\s*(const|let|var|function|class|export|import|return)` returns a single match — a legitimate `// formula expression` comment fragment.
