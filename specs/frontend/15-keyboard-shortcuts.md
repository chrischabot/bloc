# Keyboard Shortcuts

Bindings below assume macOS (`Cmd`); on Windows/Linux substitute `Ctrl`.

## App-wide

| Shortcut | Action |
|----------|--------|
| `Cmd+K` | Quick switcher |
| `Cmd+P` | Quick switcher (alt) |
| `Cmd+/` | Show shortcuts cheat sheet |
| `Cmd+J` | Jump to inbox |
| `Cmd+,` | Settings |
| `Cmd+N` | New page (private) |
| `Cmd+Shift+N` | New window (deferred) |
| `Cmd+L` | Copy page link |
| `Cmd+Shift+L` | Toggle dark mode |
| `Cmd+\` | Toggle sidebar |
| `Cmd+[` | Back |
| `Cmd+]` | Forward |
| `Cmd+Shift+F` | Search workspace |
| `Cmd+Shift+M` | New comment on selection |

## Editor

### Text editing

| Shortcut | Action |
|----------|--------|
| `Cmd+B` | Bold |
| `Cmd+I` | Italic |
| `Cmd+U` | Underline |
| `Cmd+Shift+S` | Strikethrough |
| `Cmd+E` | Inline code |
| `Cmd+K` | Insert link on selection |
| `Cmd+Shift+H` | Text color picker |

### Block creation

| Shortcut | Action |
|----------|--------|
| `/` | Open slash menu |
| `Cmd+Shift+1` | Heading 1 |
| `Cmd+Shift+2` | Heading 2 |
| `Cmd+Shift+3` | Heading 3 |
| `Cmd+Shift+7` | Bulleted list |
| `Cmd+Shift+8` | Numbered list |
| `Cmd+Shift+9` | To-do |
| `Cmd+Shift+0` | Plain text |
| `Cmd+Shift+>` | Toggle list |
| `Cmd+Shift+E` | Code block |
| `---` (typed) | Divider |
| `> ` | Toggle |
| `[] ` | To-do |
| `# `,`## `,`### ` | Headings |
| `* `, `- ` | Bulleted |
| `1. ` | Numbered |

### Block navigation

| Shortcut | Action |
|----------|--------|
| `Enter` | Split / new block |
| `Shift+Enter` | Line break within block |
| `Tab` | Indent |
| `Shift+Tab` | Outdent |
| `Esc` | Select current block |
| `↑ / ↓` | Move caret line-wise; jumps blocks at edges |
| `Cmd+A` | Select block; second press selects page |
| `Cmd+D` | Duplicate block(s) |
| `Cmd+Shift+Backspace` | Delete block(s) |
| `Cmd+Shift+↑ / ↓` | Move block(s) up/down |
| `Cmd+/` | Block menu for current block |

### Mentions and inline

| Shortcut | Action |
|----------|--------|
| `@` | Person/page/date mention |
| `[[` | Page mention |
| `+` | Page mention (alt) |
| `:` | Emoji picker (after typing letters) |

### Multi-block selection

| Shortcut | Action |
|----------|--------|
| `Shift+↑ / ↓` | Extend selection by block |
| `Cmd+Shift+A` | Select entire block |

## Database

| Shortcut | Action |
|----------|--------|
| `Enter` | Open row as page |
| `Shift+Space` | Toggle checkbox |
| `Cmd+Enter` | Save quick-add row |
| `Cmd+Shift+Enter` (in cell) | Open page (alt) |

## Comments

| Shortcut | Action |
|----------|--------|
| `Cmd+Shift+M` | New comment on selection |
| `Cmd+Enter` | Send comment |
| `Esc` | Close composer |
